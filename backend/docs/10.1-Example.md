# Objectif

Ce document présente plusieurs scénarios complets d'utilisation de l'API MarketElectro.

Chaque exemple montre :

- la requête HTTP ;
- les données envoyées ;
- la réponse attendue ;
- le rôle de l'utilisateur.

---

# Scénario 1 : Création d'un compte

## Requête

```http
POST /api/auth/register
```

### Body

```json
{
    "fullName": "Josué Amegadjin",
    "email": "josue@example.com",
    "password": "123456"
}
```

---

### Réponse

```json
{
    "success": true,
    "message": "Utilisateur créé avec succès",
    "data": {
        "id": "6a62432a868285c94ad14f58",
        "fullName": "Josué Amegadjin",
        "email": "josue@example.com"
    }
}
```

---

# Scénario 2 : Connexion

## Requête

```http
POST /api/auth/login
```

### Body

```json
{
    "email": "josue@example.com",
    "password": "123456"
}
```

---

### Réponse

```json
{
    "success": true,
    "message": "Connexion réussie",
    "data": {
        "token": "<JWT_TOKEN>",
        "user": {
            "id": "6a62432a868285c94ad14f58",
            "fullName": "Josué Amegadjin",
            "email": "josue@example.com",
            "role": "customer"
        }
    }
}
```

# Scénario 4 : Création d'un produit (Administrateur)

## Requête

```http
POST /api/products
```

### Headers

```http
Authorization: Bearer <ADMIN_TOKEN>
```

### Body

```json
{
    "name": "MacBook Pro M4",
    "description": "Ordinateur portable Apple",
    "price": 2300,
    "image": "/assets/macbook.jpg",
    "category": "Ordinateurs",
    "stock": 20
}
```

---

### Réponse

```json
{
    "success": true,
    "message": "Produit créé avec succès",
    "data": {
        "_id": "6a65ba09d5996d86848e02b9",
        "name": "MacBook Pro M4"
    }
}
```

# Scénario 6 : Ajouter un produit au panier

## Requête

```http
POST /api/cart
```

```http

```

```json

    "productId": "6a65ba09d5996d86848e02b9",
    "quantity": 5
}

                    "name": "MacBook Pro M4"
                },
                "quantity": 5
            }
        ]
    }
}
```

# Exemple d'erreur

## Requête

```http
GET /api/auth/profile
```

Sans envoyer de token.

---

### Réponse

```json
{
    "success": false,
    "message": "Accès refusé. Aucun token fourni."
}
```

# Flux complet de l'application

```text
                 INSCRIPTION
                      │
                      ▼
              POST /auth/register
                      │
                      ▼
              Connexion utilisateur
                      │
                      ▼
                POST /auth/login
                      │
                      ▼
                Réception du JWT
                      │
                      ▼
              Consultation produits
                      │
                      ▼
          Ajout des produits au panier
                      │
                      ▼
             Consultation du panier
                      │
                      ▼
           Validation de la commande
                      │
                      ▼
             Mise à jour du stock
                      │
                      ▼
             Historique des commandes
```

# Résumé

Les exemples présentés dans ce document permettent de reproduire le fonctionnement complet de l'API avec Postman ou tout autre client HTTP.

Ils constituent une référence pratique pour le développement du frontend ainsi que pour les futurs développeurs amenés à maintenir ou faire évoluer le projet.
